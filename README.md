# 微光摄影社官网 · Glimmer Photography Agency

柳铁一中微光摄影社官方网站。具备学校官方社团背书、由学生团队独立自主运营的原创影像创作社团。

> 汇聚细碎光影，留存滚烫青春。
> 以微小之姿看世界，以虔诚之姿定光影。

## 技术栈

纯静态站点：**原生 HTML + CSS + JavaScript**，无框架、无构建步骤、无第三方依赖。

双击 `index.html` 即可在浏览器打开（`file://` 下也能完整运行，作品数据以 JS 变量形式内联，不依赖 `fetch`）。

## 页面

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页：轮播 Hero、社团理念、两大创作板块、三组作品精选、原创声明、加入 CTA |
| `gallery.html` | 作品集：60 张作品、分类筛选、分步加载、灯箱浏览 |
| `about.html` | 关于我们：品牌故事、创作板块、零门槛承诺、原创原则与平台说明 |
| `join.html` | 加入微光：入社流程、报名表单、招新海报墙、常见问题 |

## 目录结构

```
├── assets/
│   ├── css/main.css       设计系统（明亮胶片感：暖米白纸感 + 暗房红 + 暖金）
│   ├── js/site.js         导航/页脚注入、滚动入场、片头遮罩、灯箱
│   ├── js/home.js         首页轮播与精选作品渲染
│   ├── js/gallery.js      作品集筛选、分步加载
│   ├── data/works.js      作品数据（window.WORKS）
│   └── img/               works（作品）/ hero（大图）/ brand（品牌资产）
├── _tools/build_assets.py 素材构建脚本
└── _tools/_frame.html     窄屏调试用 iframe 容器
```

## 本地预览

```bash
python -m http.server 8848
# 打开 http://127.0.0.1:8848/index.html
```

## 素材与构建

原始照片存放在 `摄影社素材（网站）/`，**不入库**（已由 `.gitignore` 排除）。

修改作品清单后重新生成 `assets/img/` 与作品数据：

```bash
python _tools/build_assets.py
```

输出规格：作品 1800px 大图 + 880px 缩略图（WebP）、Hero 最长边 2000px、品牌素材保留透明通道 PNG。

## 调试

给任意页面加 `?shot=1` 可关闭全部动效、直接呈现最终状态，方便截图验收；配合 `&begin=4000` 可用负 margin 偏移截取长页面的任意段落。
