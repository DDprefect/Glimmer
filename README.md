## 微光摄影社官网

柳铁一中**微光摄影社**的官方网站。社团拥有学校官方社团背书，但**由学生团队独立自主运营**——从拍摄、编辑、排版到上线部署，全部由社员自己完成。

网站取「明亮胶片感」的视觉语言：暖米白纸感背景、相纸白框、暗房红与暖金点缀，配合电影化的片头节奏，把一批社员原创实拍作品安放得安静而克制。

> 技术实现：前端为原生 HTML / CSS / JavaScript（无框架、无构建步骤）；作品投稿、报名与管理后台由 Vercel Serverless 接口、腾讯云 COS 图片存储与 Supabase 数据库支撑，git push 即自动部署。

## 你会看到什么

网站按题材分为四个板块，目前共 **74 张**社员原创实拍作品：

| 板块 | 内容 |
| --- | --- |
| **校园纪实** | 高三喊楼的声浪、运动会的奔跑、校园四季的光影 |
| **校外采风** | 玉武三江的侗寨风雨桥、云雾梯田、赶集的人与采茶的少年 |
| **城市与远方** | 柳州街巷、柳江落日、山野与远方 |
| **人像与视觉** | 国风写真、自然光与逆光、舞台纪实、校园互拍（21 张） |

所有作品均为**社员原创实拍**，带有「微光」水印，禁止搬运与商用。

## 怎么逛这个网站

- **首页**：电影感大图轮播，顶部一条**招新状态条**（招新中直接去报名，结束后引导加 QQ 群等通知），四大板块的精选作品，「最新收录」里能看到同学刚通过审核的投稿，还有一块**近期动态**说清社团最近在忙什么，以及社团自成立以来的「运行时长」计时器。
- **作品集**：按板块筛选作品，向下滚动分批加载；筛选栏右侧常驻**投稿入口**。点开任意一张即可进入灯箱，**查看大图与拍摄信息**（机型、镜头、光圈、快门、ISO、焦段），并可**一键复制这张作品的专属链接**——发给同学，点开就是那一张。新投稿通过审核后会自动出现在这里。
- **作品投稿**：同学自助投稿通道——选分类、填标题与署名、选图上传，浏览器自动压缩、自动读取拍摄参数后经服务端写入，干部审核通过即带着署名上线；投稿后还能在页尾自查审核进度。
- **关于我们**：社团的来历、创作理念、**四个部门的逐一介绍**，以及「零门槛、不唯设备」的招新态度与招募说明。
- **加入微光**：报名方式、入社流程与常见问题；报名信息一键提交进社团报名库，无需再手动转发，报名后还能**自查「待联系 / 已联系」**。
- **分享微光**：官方抖音与官方 QQ 的关注入口（附二维码），以及把本站分享出去的方式。
- **页脚**：官方 QQ 群号与抖音号就放在这里，**点一下直接复制**——想加群、想问问题，不用再到处翻。

网站适配手机与平板，在任意屏幕宽度下都能完整浏览。

## 体验亮点

- **电影感 Hero 轮播**：首页大图缓慢推近（Ken Burns），交叉淡入，不抢内容。
- **瀑布流作品集**：横竖构图混排自适应，比例经过统一钳制，版面不参差。
- **投稿即上线**：同学在前端选图后自动压缩（约 300KB）、自动带上拍摄参数，经服务端写入云端存储，作品进「待审核」队列；干部在管理后台一键通过，作品集即刻更新，署名同步展示。
- **分类筛选 + 灯箱**：按板块快速定位；灯箱里除了大图，还会展示这张照片的拍摄参数。
- **作品可以单独分享**：灯箱里一键复制这张作品的专属链接，发进群里点开就是那一张。
- **一进站就知道能不能报名**：首页顶部招新状态条，招新期间直达报名表，结束后引导加官方 QQ 群等通知；报名之后还能自查「待联系 / 已联系」。
- **「运行时长」实时计时器**：自 2016-09-10 起实时走动，年 / 天 / 时 / 分 / 秒分层呈现，里程表式滚动。
- **胶片颗粒质感**：全局细微噪点覆膜，模拟胶片纹理。
- **响应式**：从桌面到手机，版式、字号、间距随屏幕自然收放。

### v2.0.8 · 2026-10-25 · 投稿来源拦截修复

- **修复**｜有同学反馈投稿时报「**来源不受支持**」。排查发现接口的来源校验过于严格：只认 `https://` 的本站域名，从 `http://`、带端口、本地调试或镜像域打开页面时，投稿会被误拦。现已放宽——**只拦截明确来自外部网站的请求**，`http`、任意端口、任意层级子域、Vercel 部署域与本地调试一律放行；被拦时报错会带上收到的来源，截图即可定位。
- **优化**｜投稿失败的提示现在会附带**页面地址**，以后遇到上传问题一眼就能看出是从哪个域打开的，不用再猜。
- 说明：投稿与报名另有限流、全局熔断、图片格式校验与人工审核多重防护，来源检查只是最外层的一道，不影响正常使用。
